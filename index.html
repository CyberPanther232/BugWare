Scope & Ethics

Why this exists and the boundaries it is built within.

01 / PURPOSE

Defensive by intent

Every project reproduces an attacker technique so that defenders, students and researchers can study how it works and build detections against it.

02 / BOUNDARIES

Authorized use only

Use these tools only against systems you own or have explicit written permission to test. Never against third parties or production systems.

03 / CONTAINMENT

Isolated lab

Run everything in a sandboxed VM with no network path to anything you care about. No pre-built binaries are published; nothing here is drop-and-run.

04 / COMPLIANCE

Within GitHub's rules

The repository ships with clear disclaimers and a security policy, and a CI check blocks committed executables and other prohibited artifacts.

! Disclaimer

This repository and site are for ethical, academic and security-research purposes only. The projects are proof-of-concept demonstrations created to advance cybersecurity education and defense. Do not use this software for illegal or malicious purposes, and do not run it against systems you do not own or lack explicit permission to test. The author accepts no responsibility for misuse. Always work in an isolated, sandboxed environment.
