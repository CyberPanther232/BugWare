# Security Policy

## Supported Versions

Since this is a research repository, specific versions are not maintained for long-term support. The code is provided "as-is" for educational analysis.

## Reporting a Vulnerability

If you identify any artifacts, binaries, or techniques from this repository being used maliciously in the wild, or if you discover a security vulnerability within the tools themselves that could be abused:

1.  **Please report it immediately.**
2.  Contact the repository owner via GitHub Issues or private communication channels if listed.
3.  Provide details on where the artifact was found or how the vulnerability works.

## Disclaimer

**This repository contains malware samples, exploit code, and offensive security tools for educational and research purposes only.**

*   **Do not** use this code against systems you do not own or do not have explicit permission to test.
*   **Do not** use this code for any illegal or malicious activities.
*   The author takes no responsibility for any misuse of the information or code provided herein.
*   Always run these samples in an isolated, sandboxed environment (e.g., a virtual machine with no network access to production systems).
