# C2 (Command & Control)

## Overview
This project is a basic Command and Control (C2) server implementation built with Python (Flask). It demonstrates the fundamental concepts of C2 architecture, including agent check-ins (heartbeats) and command queuing.

**For Educational and Security Research Purposes Only.**

## Key Components
*   **c2.py**: The main Flask application handling agent communication.
*   **Templates**: Web interface for interacting with connected agents.

## Usage
1.  Install dependencies (Flask).
2.  Run the server: `python c2.py`
3.  Access the web interface to view connected agents and queue commands.
